# HTML & JavaScript Essentials - 3 Hour Interactive Course

A comprehensive, self-contained interactive course designed to teach HTML and JavaScript fundamentals to programmers with experience in Java, C++, or Python.

## 📚 Overview

This is a complete 3-hour intensive course that covers everything you need to get started with web development. The course is structured as a single HTML file that runs entirely in your browser - no server, dependencies, or installation required!

## ✨ Features

### 🎯 Interactive Learning
- **10 comprehensive lessons** covering HTML fundamentals through building a complete Todo app
- **Live code examples** with syntax highlighting (Atom One Dark theme)
- **Interactive demos** in every lesson - learn by doing!
- **"Show Code" buttons** reveal both HTML and JavaScript for every demo
- **Live Preview** feature lets you see HTML code render in real-time

### 📖 Learning Tools
- **Table of Contents** sidebar for easy navigation between lessons
- **Copy buttons** on all code blocks for quick code grabbing
- **Further Reading** sections with curated links to MDN, JavaScript.info, W3Schools, etc.
- **Progress tracking** bar shows your course completion
- **Syntax-highlighted code** with proper indentation

### 🎨 Professional Design
- Clean, modern interface with responsive layout
- Works on desktop, tablet, and mobile devices
- Sticky sidebar navigation on wide screens
- Collapsible code sections to reduce clutter

## 📋 Course Contents

### Lesson 1: HTML Fundamentals (15 min)
- HTML structure and essential elements
- Tags, attributes, and basic syntax
- Comparison to Java/C++ object instantiation

### Lesson 2: Forms and User Input (15 min)
- Form elements and input types
- Form validation and submission
- Handling user data

### Lesson 3: JavaScript Fundamentals (20 min)
- Variables, data types, and functions
- Comparison to Java/C++/Python syntax
- Arrow functions and modern JavaScript

### Lesson 4: DOM Manipulation (20 min)
- Selecting and modifying HTML elements
- Changing content, attributes, and styles
- Understanding the DOM tree structure

### Lesson 5: Event Handling (20 min)
- Click, input, and keyboard events
- Event listeners and event objects
- Event-driven programming concepts

### Lesson 6: Arrays and Iteration (15 min)
- Array methods: map, filter, reduce
- Functional programming in JavaScript
- Comparison to Java Streams and Python list comprehensions

### Lesson 7: Objects and JSON (15 min)
- JavaScript objects and properties
- JSON format and parsing
- Working with key-value pairs

### Lesson 8: Asynchronous JavaScript (20 min)
- setTimeout and setInterval
- Promises and async/await
- Handling asynchronous operations

### Lesson 9: Mini Project - Todo List (30 min)
- Building a complete application
- Combining HTML, CSS, and JavaScript
- CRUD operations and state management

### Lesson 10: Next Steps & Best Practices (10 min)
- JavaScript best practices
- Common gotchas and pitfalls
- Learning roadmap for continued growth

## 🚀 Getting Started

### Quick Start
1. Open `index.html` in any modern web browser
2. That's it! The course runs entirely offline

### Recommended Browsers
- Chrome, Firefox, Safari, or Edge (latest versions)
- JavaScript must be enabled

### No Installation Required
- No Node.js, npm, or build tools needed
- No internet connection required after download
- All dependencies loaded from CDN (Highlight.js for syntax highlighting)

## 💡 How to Use

### Navigation
- Use the **Table of Contents** on the left to jump to any lesson
- Click **Previous/Next** buttons to move through lessons sequentially
- Your progress is tracked at the top of the page

### Code Examples
- Click **Copy** to copy any code snippet
- Click **Live Preview** to see HTML code render in real-time
- Click **Show Code** on interactive demos to see both HTML and JavaScript

### Interactive Demos
- Try out each interactive demo by following the instructions
- Click **Show Code** to see how it's implemented
- Copy the code to use in your own projects

### Learning Tips
1. **Follow in order** - Lessons build on each other
2. **Try the demos** - Don't just read, interact!
3. **View the code** - Use "Show Code" to understand implementations
4. **Copy and experiment** - Take code snippets and modify them
5. **Use Further Reading** - Dive deeper with curated resources
