Lesson 1: HTML Fundamentals (15 min)

HTML (HyperText Markup Language) is the skeleton of web pages. Unlike Java/C++/Python which are imperative, HTML is declarative - you describe what you want, not how to create it.

Coming from C++/Java: Think of HTML as declaring objects with properties, not executing sequential instructions. Each HTML element is like instantiating an object with attributes.

Basic Structure

HTML 
<!DOCTYPE html>
<html>
  <head>
    <title>Page Title</title>
  </head>
  <body>
    <h1>Hello World</h1>
    <p>Your content here</p>
  </body>
</html>
Key Concept: HTML uses tags (opening and closing) to define elements. Most tags come in pairs: <tag>content</tag>

Essential Elements

Element Purpose Example
<h1> to <h6> Headings (h1 largest) <h1>Main Title</h1>
<p> Paragraph <p>Text content</p>
<div> Container (block-level) <div>Group content</div>
<span> Container (inline) <span>Inline text</span>
<a> Link <a href="url">Link</a>
<img> Image (self-closing) <img src="url" alt="desc">

Lesson 2: Forms and User Input (15 min)

Forms collect user data. In backend languages you might use Scanner (Java) or cin (C++). In HTML, forms handle input declaratively.

Comparison to Java/C++:
Java: Scanner scanner = new Scanner(System.in);
HTML: <input type="text"> - browser handles the input mechanism

Common Input Types

example.html 
<form>
  <input type="text" placeholder="Name">
  <input type="email" placeholder="Email">
  <input type="password" placeholder="Password">
  <input type="number" min="0" max="100">
  <input type="checkbox"> Remember me
  <input type="radio" name="choice"> Option 1
  <textarea rows="4"></textarea>
  <select>
    <option>Choose</option>
    <option>Option 1</option>
  </select>
  <button type="submit">Submit</button>
</form>
Key Concept: The 'name' attribute identifies form fields (like variable names), 'id' uniquely identifies elements for JavaScript access, and 'value' holds the data.

Lesson 3: JavaScript Fundamentals (20 min)

JavaScript is the programming language of the web. It runs in the browser and makes pages interactive.

JavaScript vs Java/C++/Python:
  • Dynamically typed - like Python, no type declarations needed
  • Event-driven - responds to user actions (clicks, input, etc.)
  • Interpreted - no compilation step
  • Prototype-based OOP - different from Java's class-based OOP

Variables and Data Types

example.html 
// Modern JavaScript uses let and const (not var)
let name = "Alice";           // String
let age = 25;                 // Number
let isStudent = true;         // Boolean
let courses = ["HTML", "JS"]; // Array
let person = {                // Object (like dict in Python, HashMap in Java)
    name: "Alice",
    age: 25
};

const PI = 3.14159;           // Constant (cannot reassign)
Key Differences from C++/Java:
  • No int, double, char - just 'number' type
  • Arrays are dynamic (like Python lists or Java ArrayList)
  • Objects are like HashMaps with string keys
  • Strings can use single or double quotes (or backticks for templates)

Functions

example.html 
// Function declaration (similar to Java/C++)
function greet(name) {
    return "Hello, " + name;
}

// Arrow function (like lambda in Java/C++ or lambda in Python)
const greetArrow = (name) => "Hello, " + name;

// Function with default parameter
function power(base, exponent = 2) {
    return Math.pow(base, exponent);
}

Lesson 4: DOM Manipulation (20 min)

The DOM (Document Object Model) is how JavaScript interacts with HTML. Think of it as an API for the webpage.

Analogy for C++/Java Programmers:
The DOM is like a tree data structure where each HTML element is a node. JavaScript provides methods to traverse and modify this tree, similar to working with a tree structure in DSA.

Selecting Elements

example.html 
// Get element by ID
let element = document.getElementById("myId");

// Get elements by class name (returns collection)
let elements = document.getElementsByClassName("myClass");

// Query selector (CSS-style, returns first match)
let elem = document.querySelector(".myClass");

// Query selector all (returns NodeList - like array)
let allElems = document.querySelectorAll("p");

Modifying Elements

example.html 
// Change text content
element.textContent = "New text";
element.innerHTML = "<strong>Bold text</strong>";

// Change attributes
element.setAttribute("class", "highlight");
element.src = "newimage.jpg";

// Change styles
element.style.color = "blue";
element.style.fontSize = "20px";

// Add/remove classes
element.classList.add("active");
element.classList.remove("hidden");
element.classList.toggle("selected");
Key Concept: innerHTML vs textContent:
  • textContent - sets/gets plain text (safe, fast)
  • innerHTML - sets/gets HTML (can parse tags, but slower)

Lesson 5: Event Handling (20 min)

Events make web pages interactive. They're triggered by user actions like clicks, key presses, mouse movements, etc.

Event-Driven Programming: Unlike procedural programs that execute top-to-bottom, JavaScript waits for events and responds to them. This is similar to GUI programming in Java (ActionListener) or callback functions in C++.

Common Events

Event Triggered When Example
click Element is clicked Button clicks
input Input value changes Typing in text field
change Input loses focus after change Dropdown selection
submit Form is submitted Form submission
keydown/keyup Key is pressed/released Keyboard shortcuts
mouseover/mouseout Mouse enters/leaves element Hover effects

Adding Event Listeners

example.html 
// Method 1: Inline (not recommended for large projects)
<button onclick="handleClick()">Click Me</button>

// Method 2: addEventListener (preferred, more flexible)
let button = document.getElementById("myButton");
button.addEventListener("click", function(event) {
    console.log("Button clicked!");
    console.log("Event object:", event);
});

// Method 3: Arrow function
button.addEventListener("click", (event) => {
    console.log("Clicked at:", event.clientX, event.clientY);
});

// Remove event listener
button.removeEventListener("click", handleClick);
The Event Object: Event handlers receive an event object (like parameter 'e' or 'event') that contains information about the event:
  • event.target - element that triggered the event
  • event.preventDefault() - prevents default behavior (e.g., form submission)
  • event.stopPropagation() - prevents event bubbling

Lesson 6: Arrays and Iteration (15 min)

JavaScript arrays are dynamic and come with powerful built-in methods, similar to Python lists or Java's ArrayList.

Array Basics

example.html 
let numbers = [1, 2, 3, 4, 5];
let mixed = [1, "hello", true, {name: "Alice"}]; // Can hold different types

// Array methods
numbers.push(6);           // Add to end
numbers.pop();             // Remove from end
numbers.unshift(0);        // Add to start
numbers.shift();           // Remove from start
numbers.length;            // Get length
numbers.includes(3);       // Check if contains value
numbers.indexOf(3);        // Find index of value

Modern Array Methods (Functional Programming)

example.html 
let numbers = [1, 2, 3, 4, 5];

// forEach - execute function for each element (like for-each in Java)
numbers.forEach((num) => {
    console.log(num);
});

// map - transform each element, return new array (like Stream.map in Java)
let doubled = numbers.map((num) => num * 2);  // [2, 4, 6, 8, 10]

// filter - keep elements that pass test (like Stream.filter in Java)
let evens = numbers.filter((num) => num % 2 === 0);  // [2, 4]

// reduce - combine all elements into single value
let sum = numbers.reduce((total, num) => total + num, 0);  // 15

// find - return first element that matches
let found = numbers.find((num) => num > 3);  // 4

// some - check if any element passes test
let hasEven = numbers.some((num) => num % 2 === 0);  // true

// every - check if all elements pass test
let allPositive = numbers.every((num) => num > 0);  // true
Comparison to Other Languages:
JavaScript Python Java
array.map(fn) map(fn, list) stream.map(fn)
array.filter(fn) filter(fn, list) stream.filter(fn)
array.reduce(fn) reduce(fn, list) stream.reduce(fn)

Lesson 7: Objects and JSON (15 min)

JavaScript objects are key-value pairs, similar to Python dictionaries or Java HashMaps, but more flexible.

Object Basics

example.html 
// Object literal
let person = {
    name: "Alice",
    age: 25,
    isStudent: true,
    courses: ["HTML", "JavaScript"],
    greet: function() {
        return "Hello, I'm " + this.name;
    }
};

// Accessing properties
console.log(person.name);        // Dot notation
console.log(person["age"]);      // Bracket notation (useful for dynamic keys)

// Adding properties
person.email = "alice@example.com";

// Deleting properties
delete person.age;

// Check if property exists
"name" in person;                // true
person.hasOwnProperty("name");   // true

Object Methods and 'this'

example.html 
let calculator = {
    result: 0,
    add: function(num) {
        this.result += num;  // 'this' refers to the calculator object
        return this;         // Return 'this' for method chaining
    },
    multiply: function(num) {
        this.result *= num;
        return this;
    },
    getResult: function() {
        return this.result;
    }
};

// Method chaining
calculator.add(5).multiply(2).add(3);  // Result: 13
JSON (JavaScript Object Notation): JSON is a text format for data exchange. It looks like JavaScript objects but:
  • Keys must be in double quotes
  • Values can be: strings, numbers, booleans, arrays, objects, null
  • No functions, undefined, or comments allowed
example.html 
// Converting between objects and JSON
let person = {name: "Alice", age: 25};

// Object to JSON string
let jsonString = JSON.stringify(person);  // '{"name":"Alice","age":25}'

// JSON string to object
let obj = JSON.parse(jsonString);         // {name: "Alice", age: 25}

Lesson 8: Asynchronous JavaScript (20 min)

JavaScript is single-threaded but handles asynchronous operations (like network requests, timers) without blocking.

Comparison to Threading: Unlike Java threads or C++ async, JavaScript uses an event loop. Operations don't run in parallel, but long-running tasks (like API calls) don't block other code from executing.

setTimeout and setInterval

example.html 
// Execute once after delay (milliseconds)
setTimeout(() => {
    console.log("Executed after 2 seconds");
}, 2000);

// Execute repeatedly at interval
let intervalId = setInterval(() => {
    console.log("Repeated every 1 second");
}, 1000);

// Stop interval
clearInterval(intervalId);

Promises

example.html 
// A Promise represents a future value (like Future in Java or Promise in C++)
let promise = new Promise((resolve, reject) => {
    // Simulating async operation
    setTimeout(() => {
        let success = true;
        if (success) {
            resolve("Operation successful!");
        } else {
            reject("Operation failed!");
        }
    }, 1000);
});

// Using the promise
promise
    .then((result) => {
        console.log(result);  // Called if resolved
    })
    .catch((error) => {
        console.log(error);   // Called if rejected
    });

Async/Await (Modern Approach)

example.html 
// async function returns a Promise
async function fetchData() {
    try {
        // await pauses execution until Promise resolves
        let response = await fetch('https://api.example.com/data');
        let data = await response.json();
        return data;
    } catch (error) {
        console.log("Error:", error);
    }
}

// Call async function
fetchData().then(data => console.log(data));
Key Concept:
  • async/await makes asynchronous code look synchronous
  • Always use try/catch with await to handle errors
  • await can only be used inside async functions

Lesson 9: Mini Project - Todo List (30 min)

Let's combine everything you've learned to build a functional todo list application!

What This Project Covers:
  • HTML structure and forms
  • Event handling (click, submit, keypress)
  • DOM manipulation (create, update, delete elements)
  • Array operations (add, filter, map)
  • LocalStorage API (data persistence)

The Code

example.html 
// HTML structure is already below in the demo
// This is the JavaScript that powers it:

let todos = [];

function addTodo() {
    let input = document.getElementById('todoInput');
    let text = input.value.trim();
    
    if (text) {
        let todo = {
            id: Date.now(),
            text: text,
            completed: false
        };
        todos.push(todo);
        input.value = '';
        renderTodos();
    }
}

function toggleTodo(id) {
    todos = todos.map(todo => 
        todo.id === id ? {...todo, completed: !todo.completed} : todo
    );
    renderTodos();
}

function deleteTodo(id) {
    todos = todos.filter(todo => todo.id !== id);
    renderTodos();
}

function renderTodos() {
    let container = document.getElementById('todoList');
    container.innerHTML = '';
    
    todos.forEach(todo => {
        let div = document.createElement('div');
        div.className = 'todo-item' + (todo.completed ? ' completed' : '');
        div.innerHTML = `
            <span onclick="toggleTodo(${todo.id})">${todo.text}</span>
            <button onclick="deleteTodo(${todo.id})">Delete</button>
        `;
        container.appendChild(div);
    });
}

Lesson 10: Next Steps & Best Practices (10 min)

Best Practices You've Learned

  • Use const and let instead of var
  • Use === instead of == (strict equality)
  • Use arrow functions for concise syntax
  • Use template literals for string interpolation: `Hello ${name}`
  • Use array methods (map, filter, reduce) over loops
  • Use async/await over callbacks
  • Always validate user input
  • Use event delegation for dynamic content

Common Gotchas (Different from C++/Java)

Issue Explanation Solution
== vs === == does type coercion: "5" == 5 is true Always use === for strict equality
'this' keyword this depends on how function is called Use arrow functions or .bind()
Hoisting var and function declarations are "hoisted" Use let/const, declare before use
Truthy/Falsy 0, "", null, undefined, NaN are falsy Use explicit comparisons
Array/Object comparison [] === [] is false (reference comparison) Compare values, not references
